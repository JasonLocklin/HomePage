I'll get to Unix shortly, but bear with me while I tell you a little about machine shops. These are the full set of tools that machinists use to fabricate all types of metal objects.
What's interesting about that? Well, first, they are self-replicating. A skilled machinist, given enough time can create just about anything. Not because their shops are
somehow the be-all-end-all of fabrication, but because the machinists tools are made by machinist tools. If their tools are insufficient, they could (at least theoretically) fabricate
better and better tools, entire machine shops can create entire, better, higher precision machine shops. And of course machinists collaborate to iterate and improve, share designs and products. They are
both the tool creators and the tool users. Sound a little familiar?

The Unix-type operating system is fairly unique in the world of both computer operating systems and technology in general. Initially a product designed by authors and sold to users, a strange convalescence
of hacker-minded computer science academics transformed it into a machinists workshop. Unix became, and its offspring today, is a workshop with a complete set of tools to build new tools. It's self-replicating (of
course), but also self-replicating in a way that using its own tools, can produce a better operating system. Unix is the original development environment. While the computer has been described as a bicycle
of the mind, Unix is the machine shop that can make bicycles.

Now this isn't to carry the analogy too far. Nowadays, a computer with a Unix type operating system is far more accessible than a professional machine shop, so instead of us all looking like those original Unix
hackers or a professional machinist, most of us are primarily users. But here's the thing, we are all also builders. Unix tools make it possible to create. This includes simple shell scripts that automate some
boring task, writing notes to document some odd process, or submitting some open source bug report or patch to actually improve the tools direction. Like any machine shop, most products are for use outside - we use
editors to write web pages or send an email, build a network of peers, or consume the fruits of digitized culture (both the high quality stuff and the rotten inebriating stuff, not going to go there today).

Now, note the machine shop includes far more than just the big tools for grinding and cutting. It also includes smaller tools that, for example, hold things, augmenting our manual abilities, and light up
or measure things, augmenting our senses. It also conforms to human limits, with a desk or drafting table and chair for planning, debugging ideas, producing sharable instructions.
A good machine shop extends human abilities, and so Unix includes compilers and debuggers, but also text editors, file and document management, interfaces to the information on the internet. It's the full
tool set that really creates the superpower of a skilled computer user combined with a Unix type operating system. It's such a rare happenstance of creation in the world of technology and one to celebrate.
If this comes across as inspiring, give it a turn. Think about the power afforded by the full set of tools available on a Linux distro, FreeBSD, OpenBSD, NetBSD, DragonflyBSD, etc etc etc. Pick your poison,
learn, one by one, all the tools in the shop, sharpen them, and make something. Start with a web page or shell script, it doesn't matter. It's the act of exercising the tools that builds the machinists brain,
and connects you to the thread of the Unix way.
